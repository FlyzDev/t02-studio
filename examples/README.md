# Example label: Field Notes 014

This self-contained sample demonstrates the current **English T02 Studio label designer**:

- A 50 × 80 mm label on a 53 mm thermal roll.
- A 3.5 px double outline and two independently sized frame layers (2 px corners and 3.5 px ticket).
- Separate Georgia and Courier typography, including a thicker small secondary line.
- A 75% opacity text layer, rendered consistently in the preview and PNG output.

## Files

- [`field-notes-014.json`](field-notes-014.json): editable layer-based project, version 2.
- [`field-notes-014-print.png`](field-notes-014-print.png): full-resolution monochrome print preview raster (384 dots wide).
- [`../docs/screenshots/field-notes-editor.png`](../docs/screenshots/field-notes-editor.png): screenshot of the real editor with the example loaded.

To edit it, launch T02 Studio, choose **Open** in the upper toolbar, and select `field-notes-014.json`. The editor will load the layers and styles. **Download PNG** exports a new raster; **Print** sends the design to a configured physical printer only when explicitly clicked.

The screenshots and sample were captured in an isolated browser profile with no print job. The demo content is original and contains no user-provided photos, printer identifiers, or credentials.
